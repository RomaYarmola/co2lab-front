**Вхід:** кнопка «Sign in with GitHub» (обліковий запис RomaYarmola) або Google — пошта, яку додано в Members.

Що можна робити без програміста:

- **Каталог → Категорії продукції** — назва, короткий опис, SEO-текст, фото, FAQ, метатеги. Кожне поле трьома мовами (EN / UK / RU).

- **Блог** — статті, категорії, автори. Зараз у блозі 3 демонстраційні статті — їх варто замінити на реальні.
- **Налаштування сайту** — контакти, соцмережі, SEO за замовчуванням.

Після натискання **Publish** зміни зʼявляються на сайті протягом ~5 хвилин.

Поради:
- Заповнюйте всі три мови. Якщо переклад порожній — сторінка покаже англійський текст.
- Поле «URL» (slug) заповнюється автоматично з назви, але його можна виправити. Не змінюйте slug у вже проіндексованих сторінок без потреби — це змінює адресу сторінки.
- Фото: мінімум 1200 px по довшій стороні, обовʼязково заповнити alt-текст трьома мовами.
- У групі **SEO** кожного документа: Meta title (50–60 символів) і Meta description (120–160) — це те, що показує Google у видачі.

Технічно: проєкт Sanity `2jwtaq7f`, датасет `production`, панель керування — https://www.sanity.io/manage (організація CO2Lab).

## 3. Google Search Console — індексація та позиції

**Адреса:** https://search.google.com/search-console?resource_id=sc-domain:co2lab.pro
**Ресурс:** доменний `co2lab.pro` (охоплює всі мови, http/https, з `www` і без). Підтверджено через TXT-запис у DNS.

Що дивитись:
- **Ефективність** — за якими запитами показується сайт, кліки, позиції. Дані зʼявляються через 2–3 дні після підтвердження.
- **Індексування → Сторінки** — скільки сторінок у Google, які помилки.
- **Файли Sitemap** — подано `https://www.co2lab.pro/sitemap.xml` (усередині — окремі карти для сторінок, каталогу й блогу).
- **Перевірка URL-адреси** (поле зверху) — вставити адресу нової сторінки і натиснути «Запросити індексування», щоб Google швидше її забрав.

Додати користувача: Налаштування → Користувачі та дозволи → Додати.

| Сервіс | Адреса | Ідентифікатор |

| Tag Manager | https://tagmanager.google.com → обліковий запис **CO2Lab**, контейнер **co2lab.pro** | `GTM-KNXXNLP3` |
| Analytics 4 | https://analytics.google.com → ресурс **CO2Lab** | Measurement ID `G-RRPPJNV77F` |

GTM уже встановлено на сайті й опубліковано (версія «v1 - GA4 + site events»). У ньому:
- тег Google (GA4) — усі перегляди сторінок;
- 5 тегів подій, які надсилає сайт:

| Подія | Коли спрацьовує | Параметр |
| --- | --- | --- |
| `form_submit` | форма успішно відправлена | `form_name`: `contact` (сторінка контактів), `quote` (кнопка «Запитати ціну» на товарі), `modal` (інші модалки) |
| `form_error` | відправка не вдалась | `form_name` |
| `request_quote_click` | натиснуто «Запитати ціну» | `product` — назва товару |
| `phone_click` | клік по телефону | `location`: `footer` / `contacts` |
| `email_click` | клік по email | `location` |

У GA4 ці події видно в **Звіти → Взаємодія → Події**. Щоб рахувати заявки як конверсії:
Адміністратор → Події → навпроти `form_submit` увімкнути «Позначити як ключову подію».

Дані в GA4 починають накопичуватись за 24–48 годин після першого відвідування.
